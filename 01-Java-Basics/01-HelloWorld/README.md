# Hello World in Java

## 📌 Topic

Java ka sabse basic program jo console par `Hello World` print karta hai.

## 🎯 What You Will Learn

* Java program ka basic structure
* `class` kya hoti hai
* `main()` method kya hota hai
* `System.out.println()` ka use
* Java program ko run kaise karte hain

## 💻 Code

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

## 🧠 Explanation

### `public class HelloWorld`

Ye `HelloWorld` naam ki class create karta hai.

### `public static void main(String[] args)`

Ye Java program ka entry point hai. Program execution yahin se start hota hai.

### `System.out.println()`

Iska use console par text print karne ke liye hota hai.

## ▶️ Output

```text
Hello World
```

## 🔑 Important Points

* Java file ka naam aur `public class` ka naam same hona chahiye.
* `main()` method ke bina normal Java application start nahi hoti.
* Java statements ke end me generally `;` lagta hai.
